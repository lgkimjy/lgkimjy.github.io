A Unified Framework for Kinodynamic Contact Planning and Whole-Body Control toward Safe and Balanced Task Execution

JunYoung Kim1, Jaemin Lee1
1North Carolina State University

Abstract

This paper proposes a novel unified framework that integrates feasibility analysis, contact planning, and whole-body control for humanoid robots. Safe whole-body behavior often requires additional contacts to satisfy balancing constraints while executing given tasks. We formulate a kinodynamic contact generation problem as a mixed-integer program that autonomously synthesizes feasible and task-dependent contacts using geometric and frictional information, thereby eliminating the need for predefined heuristics. The planned contacts are embedded into a whole-body controller to ensure dynamic consistency and balance of the robot within a given environment. To achieve scalability, we employ a reduced-order model and a full-body model, enabling efficient planning while preserving high-fidelity execution. The proposed framework is validated through simulation and hardware experiments using a humanoid robot, demonstrating safe whole-body behaviors.
