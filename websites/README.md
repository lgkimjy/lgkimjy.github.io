# Project Websites

각 프로젝트별로 HTML 페이지와 관련 static 파일을 보관하는 폴더입니다.

## 구조

```
_websites/
├── example-project/          # 예시 프로젝트
│   ├── index.html            # 프로젝트 페이지
│   └── static/               # 프로젝트 전용 에셋
│       ├── images/
│       ├── videos/
│       └── pdfs/
└── your-project/             # 새 프로젝트 추가 시
    ├── index.html
    └── static/
        └── ...
```

## 새 프로젝트 추가

1. `_websites/` 아래에 새 폴더 생성 (예: `_websites/my-paper-2025/`)
2. `example-project/` 를 복사해서 시작
3. `index.html` 수정 (제목, 저자, abstract 등)
4. `static/images/` 에 이미지, `static/videos/` 에 비디오, `static/pdfs/` 에 PDF 추가

## 접근 URL

- `/_websites/example-project/` 또는 `/_websites/example-project/index.html`
